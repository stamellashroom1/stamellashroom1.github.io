Custom CSS

Use "\(inline CSS)|" to apply any CSS to the following text, \rm:(CSS tag)| to remove specific elements, and \clear| to remove all. Can currently be used anywhere... Custom shortcuts:

  • b = bold
  • i = italic
  • u = underline
  • c = inline code

For example:

\b;color:red|Red and bold, \rm:color|\c|now bold code,\clear|\u| underline,\clear| and nothing.

Red and bold, now bold code, underline, and nothing.
